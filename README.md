# CX Reply Assistant

An AI-powered reply assistant for customer support agents.
Built for the Datastraw Technologies assessment.

## What it does
Helps a support agent generate a reply to a customer using the
brand's own knowledge base (return, refund, shipping and
cancellation policies).

## Project structure
- `database/` - schema and seed data
- `frontend/` - React app (coming soon)
- `supabase/functions/` - Edge Functions (coming soon)
